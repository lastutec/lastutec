Hitsitaulukko

Työkalu 2 · Laatinut: INS (YAMK) Atte Lastuvirta
⚠ KESKEN – työkalu on vielä kehitysvaiheessa. Tuloksia ei tule käyttää mitoitukseen ennen kuin laskenta on tarkastettu ja hyväksytty.

Hitsien mitoituskestävyydet pituusyksikköä kohden SFS-EN 1993-1-8 kohdan 4.5.3.2 komponenttimenetelmällä ja Suomen kansallisen liitteen (KL) mukaan. KL on määräävä. Kerroin √1, √2 tai √3 riippuu siitä, missä suunnassa voima rasittaa hitsiä.

√3 – pitkittäinen

Voima hitsin akselin suuntaan, vain τ∥. Esim. limiliitoksen kylkihitsit ja palkin uuman ja laipan välinen hitsi. Vastaa yksinkertaistettua menetelmää.

√2 – poikittainen pienahitsi

Voima kohtisuoraan hitsin akselia vastaan tasakylkisessä 90° pienahitsissä, jolloin a-tasossa σ⊥ = τ⊥. Esim. T-liitos ja otsahitsi.

√1 – kohtisuora a-tasoon

Voima kohtisuoraan a-tasoa vastaan, vain σ⊥. Esim. osatunkeumainen päittäishitsi vedossa. a = hitsin tunkeuma.

Lähtötiedot

KL SFS-EN 1993-1-1 kohta 3.2.1(1): fu saa ottaa joko taulukosta 3.1 tai tuotestandardista. Pocket Book käyttää tuotestandardin arvoja (S275: fu = 410 N/mm²). KL SFS-EN 1993-1-8 kohta 2.2(2): γM2 = 1,25 edellyttää vähintään hitsiluokkaa C.

    Laskuri välivaiheineen

      Kaavojen johtaminen √1, √2 ja √3

      Johdot noudattavat opinnäytetyötä Eloranta, J. (2015): Hitsausliitosten mitoittaminen, SAMK, liite 1 (SFS 2373 ja SFS-EN 1993-1-8).

      1. Lähtökohta: komponenttimenetelmä

        Hitsin laskentapinta on a · L. Voima F jaetaan laskentapinnalle komponenteiksi σ⊥, τ⊥ ja τ∥. Jännitystä σ∥ ei huomioida.
        Ehto 1 (von Mises): √(σ⊥² + 3(τ⊥² + τ∥²)) ≤ fu / (βw · γM2)
        Ehto 2: σ⊥ ≤ 0,9 · fu / γM2 (SFS-EN 1993-1-8 kaava 4.1; kerroin 0,9 ei ole kansallisesti valittava parametri)
        Kun vertailujännitys kirjoitetaan muotoon k · F/(a·L), saadaan fw,d = fu / (k · βw · γM2) ja Fw,Rd = fw,d · a.

      2. √3 – voima hitsin akselin suuntaan (kylkihitsi)

        τ∥ = F / (a·L), σ⊥ = τ⊥ = 0
        √(0 + 3(0 + τ∥²)) = √3 · τ∥ = √3 · F / (a·L)
        fw,d = fu / (√3 · βw · γM2) (sama kuin yksinkertaistettu menetelmä, kaava 3.5)
        Tarvittava a-mitta: a ≥ √3 · βw · γM2 · F / (fu · L)

      3. √2 – voima poikittain hitsiin (otsahitsi, T-liitos)

        Tasakylkisessä pienahitsissä laskentapinta on 45° kulmassa. Voima jakautuu tasan pinnan normaalin ja pinnan suuntaan: F/√2 kumpaankin.
        σ⊥ = τ⊥ = F / (√2 · a·L), τ∥ = 0
        √(σ⊥² + 3σ⊥²) = √4 · σ⊥ = 2 · F/(√2·a·L) = √2 · F / (a·L)
        fw,d = fu / (√2 · βw · γM2)
        Ehto 2: σ⊥ = fu/(2βwγM2) ≤ 0,9 fu/γM2 pätee, kun βw ≥ 0,56, eli aina. Ehto 1 määrää.
        Tarvittava a-mitta: a ≥ √2 · βw · γM2 · F / (fu · L)

      4. √1 – voima kohtisuoraan laskentapintaa vastaan

        σ⊥ = F / (a·L), τ⊥ = τ∥ = 0
        √(σ⊥²) = √1 · F / (a·L)
        Ehto 1: σ⊥ ≤ fu/(βwγM2). Ehto 2: σ⊥ ≤ 0,9 fu/γM2.
        Koska βw ≤ 1, on 1/βw ≥ 1 > 0,9. Siksi ehto 2 määrää aina: fw,d = 0,9 · fu / γM2
        Tarvittava a-mitta: a ≥ γM2 · F / (0,9 · fu · L)

      5. Vino voima kulmassa θ (opinnäytetyön esimerkki 3)

        τ∥ = F cos θ / (a·L), σ⊥ = τ⊥ = F sin θ / (√2 · a·L)
        √(4σ⊥² + 3τ∥²) = F/(a·L) · √(2 sin²θ + 3 cos²θ) = F/(a·L) · √(3 − sin²θ)
        θ = 0° → √3, θ = 90° → √2. Kerroin √3 on aina varmalla puolella.
        Poikittaisen ja pitkittäisen kestävyyden suhde on √3/√2 = 1,225. Sama luku on Pocket Bookin taulukossa Fw,T,Rd/Fw,L,Rd (esim. 0,76/0,62).

      6. Tarkistus: Pocket Book, s. 224 (S275, liitoskulma 90°)

        Kirjan lähtötiedot: fu = 410 N/mm² (tuotestandardi), βw = 0,85, γM2 = 1,25, a = 0,7·s.

        Laskuri antaa samat arvot, kun fu:n lähteeksi valitaan tuotestandardi. Taulukon 3.1 arvolla (S275, t ≤ 40 mm: fu = 430 N/mm²) kestävyydet ovat 430/410 = 1,049 kertaiset. KL sallii molemmat.

      7. Vertailu SFS 2373:een ja opinnäytetyön esimerkit

        SFS 2373: σvert = β · k · F/(a·L) ≤ σsall → a ≥ k · β · F / (L · σsall). Kertoimet k ovat samat.
        Esim. 1, otsahitsi (√2): F = 50 kN, L = 60 mm, Fe 37 (β = 0,7), σsall = 147 N/mm² → a ≥ √2 · 0,7 · 50 000 / (60 · 147) = 5,61 mm → a6
        Esim. 2, kylkihitsi (√3): F = 100 kN, L = 200 mm, Fe 44 (β = 0,8), σsall = 180 N/mm² → a ≥ √3 · 0,8 · 100 000 / (200 · 180) = 3,85 mm → a4
        Erot: SFS 2373 käyttää myötörajaa, Eurocode 3 murtolujuutta fu ja γM2 = 1,25. SFS 2373:n pituusrajat 8a ≤ L ≤ 100a korvautuvat Eurocodessa ehdoilla Leff ≥ max(30 mm; 6a) ja pitkän liitoksen kertoimella βLw.

      8. Rajat ja suositukset

        a ≥ 3 mm, Leff ≥ max(30 mm; 6a), pienahitsin kylkikulma 60°–120°. Leff on se pituus, jolla hitsi on täysimittainen. Muuten Leff = L − 2a (kohta 4.5.2).
        KL 2.2(2): γM2 = 1,25 edellyttää hitsiluokkaa vähintään C (SFS-EN ISO 5817). Avointa imuonteloa (ISO 6520-1, nro 2025) ei saa olla hitsin tehollisella pituudella missään hitsiluokassa.
        KL 4.5.3.2 ja 4.5.3.3: SFS-EN 10149-2/-3 terästen βw määritetään myötörajan perusteella kuten SFS-EN 10025 teräksille (S355MC → 0,90; S420MC ja S460MC → 1,00).
        Eri lujuusluokkien osien välinen hitsi mitoitetaan heikomman osan ominaisuuksilla (kohta 4.5.3.2(5)).
        Pocket Bookin taulukon oletus a ≥ 0,5·tp on kirjan suositus. Se ei ole SFS-EN 1993-1-8:n eikä KL:n vaatimus.
        Pitkässä limiliitoksessa (Lj > 150a) βLw = 1,2 − 0,2 · Lj/(150a) ≤ 1,0 (kohta 4.11(4)).
        Lämmöntuonnin nyrkkisääntö: a ≥ √t − 0,5 mm, t = paksumman liitettävän osan paksuus. Esim. t = 40 mm → a ≥ 5,9 mm → a6.
        Läpihitsatun päittäishitsin kestävyys on heikomman liitettävän osan kestävyys (kohta 4.7.1), joten sitä ei mitoiteta tällä taulukolla.

      Laskenta SFS-EN 1993-1-8:2005 ja sen Suomen kansallisen liitteen (ympäristöministeriö) mukaan; KL on määräävä. γM2 = 1,25 (hitsiluokka ≥ C).
