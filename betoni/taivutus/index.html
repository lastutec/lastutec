Rakennekuva (skitsi)

EC2:n mukainen prosessi: betonin reunapuristuma ≤ 3,5 ‰, teräksen muodonmuutoksia ei rajoiteta; μ = MEd / (b d² fcd), β = 1 − √(1 − 2μ), As = β b d fcd / fyd, sitkeä murtotapa kun β < βbd (γs 1,15 → 0,493, 1,10 → 0,485). Likimääräismenetelmä: sisäinen momenttivarsi 0,9d (laatat) tai 0,8d (palkit); pd on tasaisen kuorman kantokyky nivelellisesti tuetulla yksiaukkoisella rakenteella (M = pL²/8). Leikkaus: VRd,c = [CRd,c k (100 ρl fck)1/3 + k1 σcp] bw d ≥ (vmin + k1 σcp) bw d, CRd,c = 0,18/γc, k = 1 + √(200/d) ≤ 2, ρl ≤ 0,02, k1 = 0,15, vmin = 0,035 k3/2 fck1/2; VRd,s = fywd (Asw/s) z cot θ (pystyhaat), VRd,max = ν fcd b z / (tan θ + cot θ), z = 0,9d, ν = 0,6 (1 − fck/250). Tulokset tarkastaa laatija.
