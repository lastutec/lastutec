Työsauman leikkauskestävyys

Työkalu 4 · Laatinut: INS (YAMK) Atte Lastuvirta

Eri aikaan valettujen betonien rajapinnan leikkauskestävyys SFS-EN 1992-1-1 kohdan 6.2.5 mukaan: vRdi = c·fctd + μ·σn + ρ·fyd·(μ·sin α + cos α) ≤ 0,5·ν·fcd. Tarkastelu tehdään saumaa pitkin metrin kaistalle.

Lähtötiedot

Tulos

–kN/m · VRdi saumaa pitkin
Laskenta

Karheusluokat: hyvin sileä = teräs-, muovi- tai erikoiskäsiteltyä puumuottia vasten valettu; sileä = liukuvalettu tai ekstruuderipinta tai tärytyksen jälkeen jälkikäsittelemätön pinta; karhea = vähintään 3 mm karheus noin 40 mm välein (uritus, paljastettu kiviaines tai vastaava); vaarnattu = SFS-EN 1992-1-1 kuvan 6.9 hammastus (d ≥ 5 mm, hampaiden pituudet ≤ 10d). Jos σn on vetoa, c·fctd = 0. σn < 0,6 fcd. ρ = As / Ai. VEd on saumaan kohdistuva leikkausvoima metriä kohden; palkeissa vEdi = β·VEd / (z·bi) lasketaan erikseen. Tulokset tarkastaa laatija.
